## 👋 About Me

I am a **Python developer** focused on backend systems, AI-powered applications and automation.

I build practical tools that connect language models, APIs and external data sources: conversational agents, Discord and Telegram bots, parsers, backend services and machine learning projects.

* 🤖 Building AI agents with tool calling, memory and multimodal input
* ⚙️ Developing APIs and backend services with FastAPI and Flask
* 🕷️ Automating data collection, processing and Excel reporting
* 🧠 Exploring machine learning and generative image models
* 🐳 Deploying applications with Docker on Linux servers
* 💼 Interested in Python Backend and AI Engineering opportunities

## 🚀 Featured Projects

### [F2 — AI Image Editor](https://github.com/Akinara666/F2-AI-Image-Editor)

Local generative image editor with an infinite canvas, `txt2img`, `img2img`, inpainting, outpainting and sketch-to-image workflows.

**Stack:** Python, FastAPI, PyTorch, Diffusers, SD/SDXL, React, Fabric.js, Docker

---

### [PeaceMusic](https://github.com/Akinara666/PeaceMusic)

AI-native Discord bot that combines conversational Gemini tool calling with music playback and a multi-layer SQLite memory system.

**Stack:** Python, discord.py, Gemini API, SQLite, yt-dlp, FFmpeg, Docker
